Research Experience

Kathmandu Valley Satellite Image Segmentation
2025
Python · PyTorch · SegFormer · Stable Diffusion · ControlNet · Hugging Face · CVAT

Created a 1,224-pair hand-annotated satellite dataset of Kathmandu Valley across seven land-use classes. Developed TC-SegFormer, a custom SegFormer variant combining CSA reweighting and topology-aware soft-clDice loss, improving validation mIoU from 0.466 to 0.558. Built a ControlNet-guided Stable Diffusion pipeline to generate synthetic satellite image–mask pairs targeting underrepresented land-use classes, and evaluated their impact on downstream semantic segmentation performance. Benchmarked five segmentation architectures using spatial block and random splits with three-fold cross-validation.

ControlNet + Stable Diffusion, Smart City Generation
2025
Python · Stable Diffusion · ControlNet · Diffusers · PyTorch · Hugging Face

Built a generative pipeline combining ControlNet and Stable Diffusion to synthesize realistic smart-city satellite imagery conditioned on segmentation masks and text prompts. The system supports configurable inference with DPM++2M and Euler schedulers, LoRA weights, 2× upscaling, batch processing, and a low-VRAM mode for constrained GPUs, alongside a spatial coverage analysis module and CLI documentation for usage.
